Windows: DPS: Diagnostic Policy Service fails to start with error 4201
Important: This was authored via https://aka.ms/contentidea. Follow Content Idea
(CI) 198828 link for any updates. Author: Samuel Weng Summary/Symptom The
Diagnostic Policy Service (DPS) service fails to start. Cause The cause of this
issue is related to event trace session DiagLog. Stopping the event trace
session DiagLog triggers these errors when starting the DPS service. Article
resolution Check if ETW session DiagLog is running on your machine using tools
like Perfmon. After starting the DiagLog ETW session, try starting the DPS
service. More information The DPS trace logs may show entries like: The
Diagnostic Policy Service encountered an error in file
base\diagnosis\pdi\wdi\framework\dps\trace.c, function DpsRun, line 168: Error =
4201 The Diagnostic Policy Service encountered an error in file
