Windows Search Not Working in "OneDriveSynced" Folders on Windows 11 23H2
machines Important: This was authored via https://aka.ms/contentidea. Follow
Content Idea (CI) 200368 link for any updates. Author: Saisrinivas Chikoti
Summary/Symptom Reported on: Windows 11 23h2 Machines Reported Symptoms: When an
end user searches within File Explorer for a file or folder in a OneDrive-synced
folder, no results are displayed. Other information: Windows Search and File
Explorer search function normally without any issues. We rebuilt the index, and
under Indexing Options, OneDrive appears to be indexed under the Users
directory. Additionally, Cloud Content Search is enabled. Problem snippet :
OneDrive Sync folder problem snippet: Cause We gathered Search ETL traces and
Process Monitor logs during the reproduction of the issue by creating a test
folder. A test folder was created, and three different file types were moved
into it. These files were then hydrated by selecting "Always keep on this
device" before stopping the logs. Log Analysis: Converted and merged the ETL
traces. It shows successful indexing for all 3 different files in "Test folder"

Article resolution Later, we collected TTD traces for the explorer.exe and
SearchIndexer.exe processes. These traces revealed that the Local ID data was
incorrect. 0:005> dv Locale = 0x7d0 0:005> ?0x7d0 Evaluate expression: 2000 =
00000000`000007d0 This locale ID is not valid, the valid one is 0x2000 (8192)
TransientLangId is set to wrong value: which is 2000: which shows in process
monitor too: We went to the path: - HKEY_CURRENT_USER\Control
Panel\International\User Profile\en-BE Wrong Value: 0x7d0( 2000) The correct
value for en-BE is 0x2000 (8192 in decimal) And changed the value to 0x2000
(8192 in decimal) shown in below snippet: Then later, rebooted the machine. The
Search works as expected in the OneDrive Sync folder. A heartfelt thank you to
EE, Pablo (pgavela@microsoft.com) for his invaluable assistance in analyzing the
logs and guiding in the right direction to resolve the issue. More information
