SP_EXECUTION_OP_INSTALL_UPDATES Cause During previous windows 10 feature update
via SCCM, there was a “setupconfig.ini” stored under the below path,
%systemdrive%\Users\Default\AppData\Local\Microsoft\Windows\WSUS\SetupConfig.ini
Inside the Setupconfig.ini file: [SetupConfig] InstallLangPacks
C:\ProgramData\Temp\Inplaceupgrade\W10_22H2\LP
PostOOBE=C:\ProgramData\Temp\Inplaceupgrade\W10_22H2\Scripts\SetupComplete.cmd P
ostRollback=C:\ProgramData\Temp\Inplaceupgrade\W10_22H2\Scripts\ErrorHandler.cmd
DynamicUpdate Disable Article resolution Deleted the below reg key and then the
upgrade went successful,
%systemdrive%\Users\Default\AppData\Local\Microsoft\Windows\WSUS\SetupConfig.ini
More information If the update is delivered through Windows Update, Windows
Setup searches in a default location for a setupconfig file. You can include the
setupconfig file at
%systemdrive%\Users\Default\AppData\Local\Microsoft\Windows\WSUS\SetupConfig.ini
https://learn.microsoft.com/en-us/windows-hardware/manufacture/desktop/windows-
setup-automation-overview?view=windows-11#using-windows-update
