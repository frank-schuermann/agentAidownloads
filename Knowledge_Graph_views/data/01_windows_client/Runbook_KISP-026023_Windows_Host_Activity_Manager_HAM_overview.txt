Windows: Host Activity Manager (HAM) overview Important: This was authored via
https://aka.ms/contentidea. Follow Content Idea (CI) 195772 link for any
updates. Author: Jason Epperly Summary/Symptom Host Activity Manager (HAM) is
the component responsible for tracking packaged applications ‘activities’ that
they need to perform and ensuring that any other required applications are in
the resumed state when attempts are made to perform these activities. Examples
of packaged applications include: Universal Windows Platform (UWP) Centennial
applications On modern versions of Windows, this component lives in
PsmServiceExthost.dll which is loaded in the service host (svchost.exe)
