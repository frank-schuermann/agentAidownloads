Event ID 2017 is frequently logged on the server Important: This was authored
via https://aka.ms/contentidea. Follow Content Idea (CI) 197633 link for any
updates. Author: Sudha N Summary/Symptom Issue: Event ID 2017 is frequently
logged on the server Log Name: Application Source: Microsoft-Windows-PerfOS
Date: Event ID: 2017 Task Category: None Level: Warning Keywords: User: SYSTEM
Computer: Description: Unable to collect NUMA physical memory utilization data.
The first four bytes (DWORD) of the Data section contains the status code. This
event is not causing any performance issues on the server at this point But it
is logged multiple time every day Cause The event is logged indicating issue
with the performance counters. The counters might be damaged or out of sync,
hence flagging the event. Article resolution Rebuild the performance counters:
From elevated command prompt run the below command: Lodctr /r
