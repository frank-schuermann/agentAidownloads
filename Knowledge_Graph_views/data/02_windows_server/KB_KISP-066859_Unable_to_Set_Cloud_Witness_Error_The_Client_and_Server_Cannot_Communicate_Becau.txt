Unable to Set Cloud Witness. Error: The Client and Server Cannot Communicate,
Because They do Not Possess a Common Algorithm Important: This was authored via
https://aka.ms/contentidea. Follow Content Idea (CI) 201420 link for any
updates. Author: Gregory Mourougandy Summary/Symptom cx needs to have windows
cluster with cloud witness. “The client and server cannot communicate, because
they do not possess a common algorithm” which cx received while adding cloud
witness. Cx was following below documentation: hhttps://learn.microsoft.com/en-
us/windows-server/failover-clustering/deploy-quorum-witness Cause The
communication between storage account and cluster nodes happens on using TLS
1.0. The error appeared because TLS 1.0 was disabled on the server. To overcome
this, we can use below PowerShell commands to use TLS1.2 for cloud quorum setup.
Article resolution Ensure that both the client and server are configured to use
TLS 1.2. You can enable TLS 1.2 on the server using the following PowerShell
commands: [Net.ServicePointManager]::SecurityProtocol =
[Net.SecurityProtocolType]::Tls12 Set-ClusterQuorum -Cluster ClusterName
-CloudWitness -AccountName "NameOfStorageAccount" -AccessKey
"AccessKeyForStorageAccount"
