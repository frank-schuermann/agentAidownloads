Windows Server 2019: Machine shutdown with "Shutdown AD system because SS cache
timer expired with no DSM connectivity" Important: This was authored via
https://aka.ms/contentidea. Follow Content Idea (CI) 203438 link for any
updates. Author: Ankita Singh Basu Summary/Symptom Customer has Server 2019 and
when he logs in to the machine it shuts down within 2 - 3 minutes with a message
"Shutdown AD system because SS cache timer expired with no DSM connectivity"
However machine was booting in safe mdoe. Cause Issue was caused due to Secfsd
service from "Thales Group". Article resolution We disabled Secfsd service from
"Thales Group" from msconfig and issue was mitigated. More information Note:
First published: Jun 26, 2025
