Failure will not be ignored: A rollback will be initiated after all the
operations in the installer queue are completed; installer is
reliable[gle=0x80004005] Cause The issue occurs because the file
C:\WINDOWS\Microsoft.NET\Framework64\v2.0.50727\config\machine.config has the
"Read-Only" attribute enabled. This prevents the upgrade process from modifying
the file, causing the upgrade to fail. Resolution To resolve this issue, follow
these steps: Navigate to the directory
C:\WINDOWS\Microsoft.NET\Framework64\v2.0.50727\config\. Locate the file named
machine.config. Right-click the file and select Properties. Under the General
tab, uncheck the Read-Only attribute. Click OK to save the changes. Retry the
upgrade process. After disabling the "Read-Only" attribute, the upgrade should
complete successfully. More information Notes: First published: May 21, 2025
