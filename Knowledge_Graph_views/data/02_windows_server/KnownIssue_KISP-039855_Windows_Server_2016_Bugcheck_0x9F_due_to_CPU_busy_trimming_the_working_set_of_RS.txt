SYMPTOMS:
---------
Symptom Reported on Windows Server 2016 Reported symptoms System crashes with
bugcheck DRIVER_POWER_STATE_FAILURE, hexadecimal value 9F. But the issue can be
manifested in other ways such as high CPU, system hang or slowness or other
bugcheck codes

ROOT CAUSE:
-----------
d one of the power requests (to power on COM2 serial port) to block hence
triggering the power manager kernel component watchdog timeout mechanism (10min)
to crash the system with bugcheck DRIVER_POWER_STATE_FAILURE (9F). This is just
a symptom of the system lockup for long period of time.

IMPACT:
-------
Affects systems running the described configuration. See source KB KISP-039855
for full scope.
