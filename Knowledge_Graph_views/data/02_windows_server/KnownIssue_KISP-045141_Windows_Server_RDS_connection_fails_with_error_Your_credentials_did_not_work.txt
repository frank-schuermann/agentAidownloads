KNOWN ISSUE — KI-KISP-045141
Windows Server: RDS connection fails with error "Your credentials did not work"
================================================================================

Issue ID     : KI-KISP-045141
Severity     : P1
Status       : Workaround Available
Reported     : 2025-01-16
Last Updated : 2025-06-09
Source KB     : KISP-045141
Reference    : https://internal.evergreen.microsoft.com/en-us/topic/windows-server-rds-connection-fails-with-error-your-credentials-did-not-work-a8ac5470-cd06-0dde-a986-6090b1890bb5
Tags         : RDS, Windows

SYMPTOMS:
---------
Symptom RDP to destination, then popup below error message and RDP failed. Your
credentials did not work. Background: 1.workgroup environment. 2.local user for
RDP. Test user: **DSH Source IP: ***.4 Destination: ***.5

ROOT CAUSE:
-----------
Source system was set the lmcompatibilitylevel as 2, destination system was set
the lmcompatibilitylevel as 5, NTLM version is not matched.

IMPACT:
-------
Affects systems running the described configuration. See source KB KISP-045141
for full scope.

WORKAROUND:
-----------
We can follow below link to make NTLM version on source and destination are
matched. Path: HKLM\System\CurrentControlSet\Control\Lsa\lmcompatibilitylevel
Setting Description Registry security level Send LM & NTLM responses Client
devices use LM and NTLM authentication, and they never use NTLMv2 session
security. Domain controllers accept LM, NTLM, and NTLMv2 authentication. 0 Send
LM & NTLM – use NTLMv2 session security if negotiated Client devices use LM and
NTLM authentication, and they use NTLMv2 session security if the server supports
it. Domain controllers accept LM, NTLM, and NTLMv2 auth
