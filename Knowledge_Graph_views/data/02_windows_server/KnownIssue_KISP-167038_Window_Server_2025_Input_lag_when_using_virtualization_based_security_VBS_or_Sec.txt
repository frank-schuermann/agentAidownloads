WORKAROUND:
-----------
Bug 57780645: JPMC Timer Interrupts - Microsoft and Broadcom Collaboration -
Boards Temporary workaround for the customer - disable secure
boot/VBS(virtualization based security) More information Traces that were very
helpful in under understanding the issue: #xperf binary Download tss tool –
aka.ms/gettss Extract it and and find in Bin folder two files – xperf.exe and
perfctrl.dll on affected machine create C:\msdata folder and copy them over.
Open elevated cmd and execute: C:\msdata\xperf -? C:\msdata\xperf -on
proc_thread+loader+profile+interrupt+dpc+dispatcher+cswitch+timer+clockint
-stack
