Procedure: Unsupported devices for hosting Windows Server 2022 Important: This
was authored via https://aka.ms/Rubik. Follow Rubik 429 link for any updates.
Author: v-yinghuang@microsoft.com This article provides a list of devices that
are not supported for hosting Windows Server 2022 as of February 2023. It aims
to help you determine if your device is eligible for firmware updates or if it
can host Windows Server 2022. The following devices are not supported for
hosting Windows Server 2022 and are not eligible for firmware updates: Dell
PowerEdge R630 Dell PowerEdge R930 Server Dell PowerEdge T430 HP EliteDesk 800
G2 Mini HPE DL20 Gen9 HPE DL580 Gen9 HPE ProLiant XL420 Gen9 Intel NUC NUC6i7KYK
(desktop client system) Lenovo M93p Tiny Other legacy devices Ensure that your
hardware is compatible with the requirements of Windows Server 2022 before
attempting installation. If your device is listed above, consider upgrading to a
supported model to ensure compatibility and receive necessary firmware updates.
