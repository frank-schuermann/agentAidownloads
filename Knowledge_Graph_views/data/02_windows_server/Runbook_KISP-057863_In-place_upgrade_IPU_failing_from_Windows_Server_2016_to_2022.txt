was authored via https://aka.ms/contentidea. Follow Content Idea (CI) 200690
link for any updates. Author: Monalika Priya Summary/Symptom Keep Files and
Application option grayed out. Cause Mis-match of System Locale language and the
ISO used for upgrade. Article resolution Issue got resolved once the customer
used the ISO with English language instead of French. Notes: Support Topics:
Windows Servers\Windows Server 2016\Windows Server 2016\Windows Setup, Upgrade
and Deployment\Installing or upgrading Windows First published: Mar 27, 2025
