ADDS: GPHELP: Understanding Group Policy Object versionNumber Limits Important:
This was authored via https://aka.ms/contentidea. Follow Content Idea (CI)
198572 link for any updates. Author: Vivek Agarwal Summary When the Group Policy
Object (GPO) version number for a computer reaches its maximum value of 65535
(Decimal), any further changes made by the admin to the GPO will still be
detected by the client machines. Lab Environment: Client Machine:
Client3.contoso.com Domain Controller (DC): ContTokDCD.contoso.com GPO Name:
MSTEST-GPO5 More information Steps to Reproduce: Create a GPO: Create a GPO
named MSTEST-GPO5 and configure one computer group policy setting in it. It will
show computer version 1 (AD) and 1 (Sysvol). Example GPO GUID:
{AE143147-B206-469D-A074-0B908A12FCDC} Set Maximum Version Number: In adsiedit,
edit the GPO GUID {AE143147-B206-469D-A074-0B908A12FCDC} and set the
versionNumber attribute value to 2147483647. In the Sysvol folder for the GPO
{AE143147-B206-469D-A074-0B908A12FCDC}, set the gpt.iniversionNumber value to
2147483647. Link the GPO appropriately where the computer objects reside. It
will show computer version 65535 (AD) and 65535 (Sysvol) in GPMC.
