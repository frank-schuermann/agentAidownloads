ADDS: W32time: Windows Time sync request from client fails due to WaitTimeout
with error code “0x800705B4” Important: This was authored via
https://aka.ms/contentidea. Follow Content Idea (CI) 198559 link for any
updates. Author: Md Habib Nawaz Summary/Symptom In certain scenarios, a time
synchronization request from a client to a domain controller can fail, returning
a "WaitTimeout" error. This issue is often identified through the failure of the
Strip Chart command, which returns the error code "0x800705B4". Below is an
example of the output when attempting to sync time with the command w32tm
/stripchart /computer:Cont-DC.contoso.com /samples:5 /dataonly: Tracking Cont-
DC.contoso.com [DC:123]. Collecting 5 samples. The current time is 12/16/2024
1:17:10 PM. 13:17:10, error: 0x800705B4 13:17:13, error: 0x800705B4 13:17:16,
error: 0x800705B4 13:17:19, error: 0x800705B4 13:17:22, error: 0x800705B4 Cause
The primary cause of this issue is the disabling of the Windows Time NTP Server
provider on the domain controller via the system registry. This configuration
prevents proper time synchronization with the client. Article resolution To
resolve this issue, follow these steps: Backup the Registry: Before making any
changes to the registry, it's crucial to back up the current settings. Navigate
to HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\W32Time\ and create a backup.
Enable the NTP Server Provider: Option 1: Set the "Enabled" (DWORD) value to 1
in the following registry key:
HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\W32Time\TimeProviders\NtpServer
Option 2: Alternatively, you can delete the registry key
HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\W32Time\TimeProviders\NtpServer
after ensuring a backup is available. Restart the Windows Time Service: After
making the registry changes, restart the Windows Time service to apply the new
settings. You can do this by running the following command in the Command
Prompt: net stop w32time && net start w32time Verify Time Synchronization: Use
the Strip Chart command again to verify that the time synchronization is
functioning correctly: w32tm /stripchart /computer:<dcname> /samples:5 Ensure
that the error code "0x800705B4" is no longer present in the output. More
