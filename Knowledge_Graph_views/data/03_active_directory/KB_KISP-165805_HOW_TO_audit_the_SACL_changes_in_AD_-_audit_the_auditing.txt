HOW TO audit the SACL changes in AD - audit the auditing Important: This was
authored via https://aka.ms/contentidea. Follow Content Idea (CI) 203304 link
for any updates. Author: Kunal Patel Summary You found out DCs security log is
flooded with events due to someone/something updating SACL on objects to include
activity which can cause event flooding. eg auding "read all" on domain
partition or OUs/users which are frequently queried). How to track who made the
SACL Change More information Enable auditing Audit Directory Service Changes -
Windows 10 | Microsoft Learn Setting up "write SACL" audit Using LDP.exe Open
the object you would want to audit for SACL change. In this example, we will use
"cn=configuration,DC=contoso,DC=com" LDP.exe --> Connect ---> bind ---> view
tree ---> "cn=configuration,DC=contoso,DC=com" Right click the object -->
advance --> security descriptor --> check box on SACL --> OK You may Update the
Trustee, Access Mask, and ACE Flags as required. **Below sample will only
monitor if member of domain admin makes a SACL change. Tracking Changes in
Security logs Event generated 5136(S) A directory service object was modified. -
