ROOT CAUSE:
-----------
The primary cause of this issue is the disabling of the Windows Time NTP Server
provider on the domain controller via the system registry. This configuration
prevents proper time synchronization with the client.

IMPACT:
-------
Affects systems running the described configuration. See source KB KISP-041663
for full scope.

WORKAROUND:
-----------
To resolve this issue, follow these steps: Backup the Registry: Before making
any changes to the registry, it's crucial to back up the current settings.
Navigate to HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\W32Time\ and create a
backup. Enable the NTP Server Provider: Option 1: Set the "Enabled" (DWORD)
value to 1 in the following registry key:
HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\W32Time\TimeProviders\NtpServer
Option 2: Alternatively, you can delete the registry key
HKEY_LOCAL_MACHINE\SOFTWARE\Policies\Microsoft\W32Time\TimeProviders\NtpServer
