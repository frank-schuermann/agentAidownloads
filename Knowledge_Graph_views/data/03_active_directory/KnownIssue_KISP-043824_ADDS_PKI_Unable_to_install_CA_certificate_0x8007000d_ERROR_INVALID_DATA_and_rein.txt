-------
Affects systems running the described configuration. See source KB KISP-043824
for full scope.

WORKAROUND:
-----------
The problem was mitigated by the use of `-OverwriteExistingDatabase` switch,
which proved successful in overwriting the previous ADCS configuration and
completing the setup without further issues. Install-AdcsCertificationAuthority
-OverwriteExistingKey -OverwriteExistingCAInDS -OverwriteExistingDatabase
