KNOWN ISSUE — KI-KISP-057720
ADDS: Tools: Klist.exe fails to display ticket cache; “Credentials cache C:\Users\xxx\krb5cc_xxx not found”
================================================================================

Issue ID     : KI-KISP-057720
Severity     : P1
Status       : Workaround Available
Reported     : 2025-03-31
Last Updated : 2025-07-29
Source KB     : KISP-057720
Reference    : https://internal.evergreen.microsoft.com/en-us/topic/adds-tools-klist-exe-fails-to-display-ticket-cache-credentials-cache-c-users-xxx-krb5cc-xxx-not-found-677cc837-7c49-83f8-680b-007a1fa52062
Tags         : Active Directory, Kerberos

SYMPTOMS:
---------
Symptom You run “klist.exe” or “klist.exe tickets” in the user context, and
expect to see the user’s Kerberos tickets, however, you get this error:
“Credentials cache C:\Users\xxx\krb5cc_2280025 not found” You have validated
that there are no Kerberos issues, and the client does appear to acquire and
consume Kerberos tickets successfully. Additionally, other klist switches (like
klist get SPN) also fail, with this message:

IMPACT:
-------
Affects systems running the described configuration. See source KB KISP-057720
for full scope.

WORKAROUND:
-----------
Move the JDK path in the System variables below the default, Windows paths, so
that when you call “klist.exe” from the command line, it launches the built-in,
Microsoft version from the System32 folder. Notes: Support Topics:
Windows\Windows 11\Windows 11 Enterprise and Education, version 24H2\Windows
Security Technologies\Kerberos authentication First published: Mar 31, 2025
Keywords: Credentials cache C:\Users\xxx\krb5cc_xxx not found, klist, JDK
