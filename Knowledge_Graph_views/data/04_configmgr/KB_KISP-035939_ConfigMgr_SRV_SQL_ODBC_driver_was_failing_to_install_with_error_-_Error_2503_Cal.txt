ConfigMgr: SRV: SQL ODBC driver was failing to install with error - "Error 2503
Called RunScript when not marked in progress" and "Error 2502 Called
InstallFinalize when no install in progress." Important: This was authored via
https://aka.ms/contentidea. Follow Content Idea (CI) 197515 link for any
updates. Author: Nikhil Chandra Borkar Summary/Symptom CX was trying to upgrade
their SCCM infrastructure to latest version but the pre-req check failed with
ODBC driver install failure. we tried to install the ODBC driver manually but it
failled with following errors- "Error 2503 Called RunScript when not marked in
progress" "Error 2502 Called InstallFinalize when no install in progress." Cause
MSI installation was failing manually on the sever. no particular reason but
access denied on temp folder. Article resolution 1/ We cleaned up the
c:\windows\temp folder and made sure the file count in it is less than 64k
files. 2/ we tried the following commands to check if there was a system level
corruption- sfc /scannow DISM.exe /Online /Cleanup-Image /RestoreHealth
/Source:C:\RepairSource\Windows /LimitAccess 3/ We gave the user running the
install full access to temp folder - Go to Local Disc (C:) and open the Windows
folder. Find the Temp folder and right-click on it. Go to Properties >>>
Security tab >>> Advanced. Click on your Windows user and change the permission
to Full control. Click Apply. If you receive warning messages, click Yes and
continue. 4/ Rebooted the server and the issue still persists. 5/ We tried to
use command prompt to install the ODBC driver msi package (make sure to run the
command prompt as system context, we used psexec here) Msiexec.exe /I
“mssqlodbc.msi” /l*v “c:\temp\odbcinstall.log” 6/ This time, it went through,
and the config manger upgrade was also successful. More information
https://www.boxaid.com/blog/how-to-fix-2502-2503-errors/
https://advyon.com/solved-2502-2503-error-when-installing-from-a-msi-file/
