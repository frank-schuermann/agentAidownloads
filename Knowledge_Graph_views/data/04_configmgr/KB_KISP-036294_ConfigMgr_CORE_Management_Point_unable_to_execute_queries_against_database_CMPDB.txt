++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
+++++++++++++++++++++++++++++++++++ Cause Later customer informed that they have
removed the MP from the domain and then re-joined it. We informed the customer
that this is not supported and should not be performed. ++++++++++++++++++++++++
++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++ It's not
supported to change the following configurations for a computer that hosts a
site system role: Domain membership, including if you remove a site system from
the domain, and then rejoin the same domain. Domain name Computer name
Supporting article: Support for Active Directory domains - Configuration Manager
| Microsoft Learn ++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++++
++++++++++++++++++++++++++++++ Article resolution We removed the computer
account for the secondary site server (Proxy Management Point for which we are
getting the error) from the Primary Site Server database: Then we readded it
using the queries: CREATE LOGIN [XXXXXXXX\XXXXXXX$] FROM WINDOWS WITH
DEFAULT_DATABASE=[master], DEFAULT_LANGUAGE=[us_english] GO CREATE USER
[XXXXXXXX\XXXXXXX1$] FOR LOGIN [XXXXXXXX\XXXXXXX$] WITH DEFAULT_SCHEMA=[dbo] GO
Issue was remediated post performing the above-mentioned operation.
