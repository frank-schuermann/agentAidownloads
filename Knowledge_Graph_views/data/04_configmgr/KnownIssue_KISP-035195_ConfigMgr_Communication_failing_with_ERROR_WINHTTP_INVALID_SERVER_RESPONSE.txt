-----------

IMPACT:
-------
Affects systems running the described configuration. See source KB KISP-035195
for full scope.

WORKAROUND:
-----------
Check in IIS logs with client logs in case of any hit (as client needs to
connect to the windows_auth endpoint first, first hit will fail with 401 but
subsequent request goes through since the client get the kerb token) If no hits
are found in IIS, then: Collect netmon trace from source and destination while
browsing URL http://ABC.XYZ.COM/ccm_system/request and
http://ABC.XYZ.COM/ccm_system_windowsauth/request failed in system context.
