WORKAROUND:
-----------
We removed the computer account for the secondary site server (Proxy Management
Point for which we are getting the error) from the Primary Site Server database:
Then we readded it using the queries: CREATE LOGIN [XXXXXXXX\XXXXXXX$] FROM
WINDOWS WITH DEFAULT_DATABASE=[master], DEFAULT_LANGUAGE=[us_english] GO CREATE
USER [XXXXXXXX\XXXXXXX1$] FOR LOGIN [XXXXXXXX\XXXXXXX$] WITH
DEFAULT_SCHEMA=[dbo] GO Issue was remediated post performing the above-mentioned
operation.
