ROOT CAUSE:
-----------
ERROR_WINHTTP_SECURE_FAILURE: 12175 One or more errors were found in the Secure
Sockets Layer (SSL) certificate sent by the server.

IMPACT:
-------
Affects systems running the described configuration. See source KB KISP-046276
for full scope.

WORKAROUND:
-----------
Open Registry --> Computer\HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\S
ecurityProviders\SCHANNEL\Protocols\TLS 1.2\Client Enabled to set to 0 Changed
to 1. Initiated the client registration and the registration was successful.
More information Enable TLS 1.2 on servers - Configuration Manager | Microsoft
