Cannot set role priority for SQL role SQL "Failed to execute control code
'54526046' Important: This was authored via https://aka.ms/contentidea. Follow
Content Idea (CI) 198058 link for any updates. Author: Badal Pundir
Summary/Symptom While trying to set role priority for SQL role in failover
cluster manager you are getting error. "Failed to execute control code
'54526046' Cause (Misconfiguration of witness disk.) It was that one of the core
resources (Witness Disk) is part of the SQL Role, whereas it should be part of
Core Group. Article resolution 1, Check if witness resource is aligned in the
Core Group or not. 2, If not, you may use "Move-ClusterResource -Name resource1
-Group "group name" ". It will allow you to move the Witness resource to cluster
core group. 3, Afterwards we should be able to change the priority of the SQL
role.
