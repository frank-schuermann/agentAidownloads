================================================================================
KNOWN ISSUE — KI-KISP-042769
Error while creating a Remote Perfmon dataset
================================================================================

Issue ID     : KI-KISP-042769
Severity     : P1
Status       : Workaround Available
Reported     : 2024-12-18
Last Updated : 2025-06-09
Source KB     : KISP-042769
Reference    : https://internal.evergreen.microsoft.com/en-us/topic/error-while-creating-a-remote-perfmon-dataset-9420e29a-7395-4dc5-6e9e-27adb26ce6f4

SYMPTOMS:
---------
Symptom When a user tries to create a Remote Perfmon data set they get the
following error: "Remote Perfmon gives the following error: ""when attempting to
create the data collector set the following system error occurred, A specified
logon session does not exist, it may already have been terminated".

ROOT CAUSE:
-----------
The following Security policy is enabled on the system: “Network access: Do not
allow storage of passwords and credentials for network authentication”

IMPACT:
-------
Affects systems running the described configuration. See source KB KISP-042769
for full scope.

WORKAROUND:
-----------
Disable the following security policy: “Network access: Do not allow storage of
passwords and credentials for network authentication”
