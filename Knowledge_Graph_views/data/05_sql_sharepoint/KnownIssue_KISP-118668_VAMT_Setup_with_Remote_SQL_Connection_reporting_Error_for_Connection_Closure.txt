WORKAROUND:
-----------
While comparing the logs and post enabling the TLS 1.0 on the affected server
Issue got fixed. Additional Considerations: However, TLS 1.0 is not a secure
protocol , if you want to disable TLS 1.0 please follow the best practices from
the below document. https://docs.microsoft.com/en-
us/security/engineering/solving-tls1-problem And please enforce TLS 1.2 for the
client by following this article https://docs.microsoft.com/en-
us/mem/configmgr/core/plan-design/security/enable-tls-1-2-client Also, ensure
affected client must initiate TLS 1.2 traffic before disabling TLS 1.0. Notes:
First published
