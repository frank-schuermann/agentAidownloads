Driver Verifier false positive for ECP leak Important: This was authored via
https://aka.ms/contentidea. Follow Content Idea (CI) 197163 link for any
updates. Author: Fred Jeng Summary/Symptom With driver verified enabled, if a
filter driver attempts to free an Extra Create Parameter (ECP) buffer, driver
verifier incorrectly attributes this to the filter manager rather than the
filter driver and will bugcheck with the error "FILTER VERIFIER ERROR: A filter
tried to release/free an object that it did not own.." Article resolution
Verifier bug has been fixed in Dilithium build Bug 49376855: Verifier doesn't
track references acquired on behalf of a filter - Boards More information
