Windows: OpenSSH: SYSLOG support for SIEM integration including CVE, JSON or XML
formats in OpenSSH Important: This was authored via https://aka.ms/contentidea.
Follow Content Idea (CI) 200223 link for any updates. Author: Arren Conner
Summary Abstract Q. Is it possible for the OpenSSH syslog to support SIEM
integration (Security information and event management) solutions by exporting
the CFE , JSON or XML file formats?. OpenSSH does not appear to natively
generate syslog in CEF, JSON, or XML formats, I see syslog DOES support for
event log and file txt and not mention this. A. Per
https://github.com/PowerShell/Win32-OpenSSH/wiki/Logging-Facilities current as
of March 7, 2025, logging to event viewer or a text file is currently supported.
