SYMPTOMS:
---------
Symptom Issue/Inquiry: The existence of a WMI namespace equivalent to
"root\SecurityCenter2" on Windows Server 2019 and later, specifically to
retrieve the "productState" property.

IMPACT:
-------
Affects systems running the described configuration. See source KB KISP-035578
for full scope.

WORKAROUND:
-----------
Unfortunately, there is no WMI class equivalent to "root\SecurityCenter2" for
this purpose. The class was undocumented for a reason in older versions. The
above script uses the WscGetSecurityProviderHealth function to get the aggregate
health state of the security provider categories. For more information, you can
refer to WscGetSecurityProviderHealth function (wscapi.h) - Win32 apps |
