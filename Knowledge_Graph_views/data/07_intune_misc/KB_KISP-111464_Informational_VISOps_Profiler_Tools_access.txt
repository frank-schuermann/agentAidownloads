minimize delays in processing your CSVT requests, ensure the following
requirements are met. VISOps SNOW ticket with attached template. Download and
fill out the appropriate template for whichever tools you are requesting. You
can find the list of tool templates in KB 5050727 Informational: VISOps:

Manager (SDM) approval email.* Note: *Not all Profiler Tools need SDM approval,
review the individual Profiler Tool requirements in this article. Return to top
3. VISOps Tool access request template Complete the below listed fields in the
template. Username: v-xxxxxxx/Supplier UPN/MID with which access is needed.
Display name: Users with inaccurate display names can be missed in reporting -
Use correct First and Last names of the users. LOB: Line of Business. Region:
Region from where user is located. Business Segment: Commercial or Consumer.
Tool: Select the tool for which access is needed. Return to top 4. Individual
