Intune : How to retrieve Intune managed app version through PowerShell
Important: This was authored via https://aka.ms/contentidea. Follow Content Idea
(CI) 202800 link for any updates. Author: Aanand Jha Summary/Symptom To fetch
the version of a managed app using PowerShell in an Intune-managed environment,
you generally use the Microsoft Graph API. Cause Reviewed all available output
properties, including AdditionalProperties, but couldn’t locate any field
corresponding to the app version. Article resolution I recommend trying the
following query: Module --> Microsoft.Graph.Beta.Devices.CorporateManagement
(Get-MgBetaDeviceAppManagementMobileApp -MobileAppId
"MOBILEAPPID").AdditionalProperties Reference: In the base command, version
details are not provided by default. You need to add an additional parameter
function to retrieve the version information. Expand property capability is not
supported because additional property values or attributes are dictionary types,
attributes, or objects, not string objects. Since expand property only works
with string-type objects, using it alongside additional properties in the same
command line will not work. Instead, a second command line is required, where
you specify the base command followed by brackets and '.additionalProperties' to
get the output.
