How the Support AI Agent Uses This Graph

When a support ticket arrives, the AI agent traverses the graph to find the best resolution

1

Parse Ticket

Extract product name, error messages, symptoms, affected version, and customer from the incoming ticket.

2

Match Known Issues

Search KnownIssue nodes by matching symptoms. If found, provide the documented workaround immediately.

3

Check Release Notes & Fixes

Traverse FIXED_IN edges to see if the issue was resolved in a newer version. Recommend upgrade if applicable.

4

Find Runbooks & SOPs

Follow HAS_RUNBOOK edges from affected services to get step-by-step resolution procedures.

5

Identify Experts & Escalate

If unresolved, find the owning Team and available Experts using OWNS and ASSIGNED_TO edges. Follow SOP for escalation.

Explorer Features

What you can do in the interactive graph view

🕸️

Force-Directed Layout

D3.js powered physics simulation that auto-arranges nodes by their relationships for intuitive visual exploration.

🔍

Search & Filter

Instantly search nodes by name and filter by type — Products, Services, Experts, Incidents, and more.

📋

Node Inspector

Click any node to see all properties, tags, connected nodes, runbook steps, and resolution details in a side panel.

🔗

Relationship Traversal

Navigate between connected nodes — follow DEPENDS_ON chains, RESOLVED_BY links, and IMPACTED_BY paths.

🎯

Highlight Connections

Selecting a node highlights all its direct connections and dims everything else for focused analysis.

🖱️

Drag & Zoom

Pan, zoom, and drag nodes to rearrange the graph. Fit-to-screen with one click for the best overview.
