================================================================================
RELEASE NOTES — Microsoft Dynamics 365 Contact Center
2025 Release Wave 1 (April 2025)
================================================================================

HIGHLIGHTS:
-----------
This release brings enhanced real-time analytics, WhatsApp Business API v2,
Copilot case summarization GA, outbound dialer preview, and sentiment-based routing.

NEW FEATURES:
-------------

1. ENHANCED REAL-TIME ANALYTICS
   Completely redesigned supervisor dashboards built on Power BI:
   - Real-time queue depth, wait times, and agent status
   - Agent performance heatmaps
   - CSAT trending with drill-down
   - Export to Excel and scheduled email reports

2. WHATSAPP BUSINESS API v2
   Upgraded integration with WhatsApp Business API v2:
   - Support for interactive list messages and buttons
   - Rich media (images, documents, location) in-conversation
   - Higher throughput (1000 messages/second)
   - Template message management in admin center

3. COPILOT CASE SUMMARIZATION (GA)
   Previously in preview, now generally available:
   - Auto-generates case summary from conversation history
   - Updates case notes with key points, action items, sentiment
   - Works across voice, chat, and email channels

4. OUTBOUND DIALER (Preview)
   Preview of outbound calling capabilities:
   - Campaign-based outbound dialing
   - Click-to-call from agent desktop
   - Call list management and scheduling
   - Preview dialer mode (agent reviews before call)

5. SENTIMENT-BASED ROUTING
   Route conversations based on real-time customer sentiment:
   - Sentiment levels: Very Positive, Positive, Neutral, Negative, Very Negative
   - Configure routing rules to prioritize negative sentiment
   - Route "Very Negative" to specialized retention queue

BUG FIXES:
----------
- Fixed: Agent presence not syncing across tabs (#BUG-4201)
- Fixed: Knowledge article search returning stale results (#BUG-4189)
- Fixed: Routing diagnostics not showing classification output (#BUG-4215)
- Fixed: Email channel losing attachments > 10MB (#BUG-4178)

UPGRADE INSTRUCTIONS:
---------------------
1. Ensure Dynamics 365 environment is on latest version
2. Opt-in to 2025 Wave 1 in admin center > Settings
3. Update WhatsApp channel configuration for v2 API
4. Test Copilot summarization in sandbox before production rollout
